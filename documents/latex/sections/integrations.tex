\subsection{Resilience notes}
If \texttt{onecompiler.com} is unreachable, the CodeLab chrome still renders with an empty editor area; no fallback message or retry exists. \textbf{Status:} IMPLEMENTED (behavior) / RECOMMENDED (fallback UI, see Section~\ref{sec:roadmap}). No other integrations (analytics, auth providers, storage, email) exist. \textbf{Status:} NOT APPLICABLE.
