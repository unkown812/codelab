\subsection{Repository inventory}
The complete application source (excluding \texttt{node\_modules/}, \texttt{.next/}, \texttt{.git/}) is:

\begin{itemize}
\item \texttt{index.html} --- 563-line standalone prototype with inline CSS; contains navbar/hero/features styles but its \texttt{body} renders only the compiler section (lines 516--557).
\item \texttt{codelab/src/app/layout.tsx} --- root layout, Geist fonts, metadata, full-viewport body.
\item \texttt{codelab/src/app/page.tsx} --- home route, renders \texttt{CodeEditor} only.
\item \texttt{codelab/src/app/globals.css} --- Tailwind import plus default template variables.
\item \texttt{codelab/src/components/CodeEditor.tsx} --- 185-line reusable embed component plus \texttt{buildOneCompilerSrc} URL builder.
\item \texttt{codelab/package.json}, \texttt{next.config.ts}, \texttt{tsconfig.json}, \texttt{eslint.config.mjs}, \texttt{.gitignore} --- toolchain configuration.
\item \texttt{codelab/public/} --- default Next.js static assets (\texttt{next.svg}, \texttt{vercel.svg}, favicons); none are referenced by \texttt{page.tsx}. \textbf{Status:} IMPLEMENTED (unused assets, see Section~\ref{sec:technical-debt}).
\end{itemize}
