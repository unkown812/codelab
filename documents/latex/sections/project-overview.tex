\subsection{Repository inventory}
The complete application source (excluding \texttt{node\_modules/}, \texttt{.next/}, \texttt{.git/}) is:

\begin{itemize}
\item \texttt{src/app/} --- 17 static routes (\texttt{page.tsx} files), 2 dynamic routes (\texttt{languages/[slug]}, \texttt{blog/[slug]}), plus \texttt{layout.tsx}, \texttt{globals.css}, \texttt{robots.ts}, \texttt{sitemap.ts}, \texttt{manifest.ts}, \texttt{not-found.tsx}.
\item \texttt{src/components/} --- \texttt{Navbar}, \texttt{Footer}, \texttt{CodeEditor} (+ \texttt{buildOneCompilerSrc}), \texttt{CompilerView} (client island), \texttt{LanguageExplorer} (client island), \texttt{Breadcrumbs}, \texttt{JsonLd}.
\item \texttt{src/lib/} --- \texttt{seo.ts} (canonical site config, 12-language metadata), \texttt{posts.ts} (4 blog posts).
\item \texttt{public/} --- \texttt{favicon.png} (261x261), \texttt{favicon.ico} only.
\item Root config --- \texttt{package.json}, \texttt{package-lock.json} (npm), \texttt{next.config.ts}, \texttt{tsconfig.json}, \texttt{eslint.config.mjs}, \texttt{.gitignore}, \texttt{.editorconfig}, \texttt{LICENSE} (ISC, Jay Jogane).
\item Root docs --- \texttt{README.md}, \texttt{AGENTS.md}, \texttt{CONTRIBUTING.md}, \texttt{SECURITY.md}, \texttt{DESIGN.md}.
\item \texttt{.github/} --- CI workflow, PR template, issue templates, Dependabot config.
\item \texttt{documents/} --- this LaTeX suite (print-oriented; \texttt{src/} is the source of truth).
\end{itemize}
