\section{Development Guidelines}
\label{sec:development-guidelines}

\textbf{Status:} IMPLEMENTED (workflow as configured). Normative contributor text lives in \texttt{AGENTS.md} and \texttt{CONTRIBUTING.md}; this section summarizes it for print readers.

\subsection{Setup and commands}
Work from the repository root. Path alias \texttt{@/*} maps to \texttt{./src/*} (\texttt{tsconfig.json}). Run \texttt{npm run lint} (zero warnings), \texttt{npx tsc --noEmit}, and \texttt{npm run build} before opening a change; regenerate route types with \texttt{npx next typegen} if \texttt{LayoutProps}/\texttt{PageProps} go stale. Formatting follows \texttt{.editorconfig} (LF, 2-space indent, final newline).

\subsection{Conventions}
\begin{itemize}
\item Keep pages server-rendered with \texttt{metadata} exports; new interactivity goes in small client components (\texttt{CompilerView} and \texttt{LanguageExplorer} are the only islands).
\item Every new indexable route needs title, description, canonical URL, JSON-LD, and a \texttt{sitemap.ts} entry.
\item Keep the embed builder as the single place that knows the OneCompiler URL schema; never hand-concatenate embed URLs elsewhere.
\item Use Tailwind \texttt{@theme} tokens and \texttt{lucide-react} icons; never hardcode hex values or invent stats, customers, or offers.
\item Content datasets live in \texttt{src/lib/} (\texttt{seo.ts}, \texttt{posts.ts}); extend them instead of ad-hoc JSX.
\item Do not add backend, auth, tracking, or dependencies without a design doc and security review.
\end{itemize}

\subsection{Definition of done}
Build + lint + typecheck green, requirements met, nothing else broken, focused diff reviewed, docs (\texttt{README.md}/\texttt{AGENTS.md}, plus this suite for behavioral changes) updated, \texttt{LICENSE} terms untouched, no secrets added.
