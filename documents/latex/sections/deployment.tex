\section{Deployment}
\label{sec:deployment}

\textbf{Status:} IMPLEMENTED for local commands and CI; INFERRED for hosting (no hosting config in repo).

\subsection{Prerequisites}
Node.js with npm (versions not pinned in repo --- RECOMMENDED: pin in \texttt{.nvmrc} or \texttt{packageManager} field; CI currently builds on Node 22). Install from the repository root:

\begin{lstlisting}[language=bash,caption={Verified commands (from package.json scripts)}]
npm install
npm run dev    # local development
npm run lint   # quality gate
npm run build  # production build + type check
npm start      # serve the production build
\end{lstlisting}

\subsection{Build and hosting}
\texttt{next build} prerenders all routes (verified 2026-10-11 output: static + partial-prerender entries, dynamic \texttt{sitemap.xml}). CI (\texttt{.github/workflows/ci.yml}) runs install, lint, and build on pushes to \texttt{master} and pull requests. The app was observed serving at \texttt{https://code--lab.vercel.app/} on 2026-10-11, consistent with Vercel hosting, but no platform manifest exists in the repo, so hosting remains an operator choice. No database migrations, rollback scripts, or production env configuration exist. \textbf{Status:} NOT APPLICABLE.
