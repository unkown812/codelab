\section{Product Description}
\label{sec:project-description}

\textbf{Status:} IMPLEMENTED for features; INFERRED where user value is interpreted (marked).

\subsection{Product identity}
CodeLab is a free online compiler with editorial-grade guides: a live playground for 80+ languages plus server-rendered content (language guides, tutorials, use cases, comparisons). Product category: online code playground with documentation hub. \textbf{Status:} IMPLEMENTED.

\subsection{Problem and solution}
Problem (INFERRED): users who want to try, learn, or share code without installing toolchains need an instantly available editor \textit{and} answers to follow-up questions (stdin handling, sharing, language choice). Solution (IMPLEMENTED): the \texttt{/compiler} route fills the viewport with the OneCompiler iframe framed by CodeLab chrome, while 32 companion pages provide guides, FAQs, and comparisons in crawlable HTML.

\subsection{Target audience and personas}
The repository now encodes audiences as first-class pages under \texttt{src/app/use-cases/}: students, teachers, and interview candidates, each with a dedicated workflow page. \textbf{Status:} IMPLEMENTED (pages) / INFERRED (that these convert to product requirements---no tracker exists).

\subsection{Non-features}
User accounts, saved sessions, multi-file projects owned by CodeLab, theming beyond the embed \texttt{theme}/\texttt{fontSize} parameters, and offline execution do not exist in the repository. \textbf{Status:} NOT APPLICABLE (not implemented).
