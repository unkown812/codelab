\section{Product Description}
\label{sec:project-description}

\textbf{Status:} IMPLEMENTED for features; INFERRED where user value is interpreted (marked).

\subsection{Product identity}
CodeLab is a thin full-viewport wrapper around the OneCompiler editor embed. Product category: online code playground / compiler front end. \textbf{Status:} IMPLEMENTED.

\subsection{Problem and solution}
Problem (INFERRED): users who want to try or share code without installing toolchains need an instantly available editor. Solution (IMPLEMENTED): a single route that fills the viewport with the OneCompiler iframe, framed by a minimal dark window chrome (traffic-light dots, title, static status indicator).

\subsection{Target audience and personas}
No personas are defined in the repository. \textbf{Status:} UNKNOWN. Plausible audiences (INFERRED, not claimed as requirements): students trying small snippets, interviewers sharing a runnable page, documentation authors linking a live editor. These are listed as hypotheses only.

\subsection{Non-features}
User accounts, saved sessions, multi-file projects owned by CodeLab, theming beyond the embed \texttt{theme}/\texttt{fontSize} parameters, and offline execution do not exist in the repository. \textbf{Status:} NOT APPLICABLE (not implemented).
