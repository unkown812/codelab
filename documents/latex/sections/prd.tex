\section{Product Requirements Document (PRD)}
\label{sec:prd}

\textbf{Status:} INFERRED from implementation (no PRD exists in the repository). Nothing below should be read as a historical requirement; it reconstructs what the code actually satisfies.

\subsection{Vision and goals}
Vision (INFERRED): the fastest path from link to runnable code in a browser, with answers attached. Goals satisfied by the code: (1) runnable playground with no signup (\texttt{/compiler}); (2) every further question answered in crawlable pages (languages, stdin, sharing, use cases); (3) zero CodeLab-side code execution to operate.

\subsection{Personas and user stories}
Personas are encoded as use-case pages, not as repo requirements. \textbf{Status:} IMPLEMENTED (pages) / UNKNOWN (tracker). Reconstructed stories (INFERRED): as a student, I can run Python online without installing anything (\texttt{/languages/python}); as a teacher, I can share one link the whole room runs (\texttt{/use-cases/teachers}); as a candidate, I can drill with stdin inputs (\texttt{/use-cases/interviews}); as an embedder, I can pass \texttt{language}/\texttt{fontSize}/hide-flags to tailor the iframe per page.

\subsection{Scope}
In scope (IMPLEMENTED): playground with runtime switcher, 12 language guides, 4 blog guides, 3 use-case pages, 1 comparison (+ hub), legal/contact/about pages, SEO/AEO/GEO infrastructure, CI lint+build gates. Out of scope (NOT APPLICABLE): accounts, persistence, collaboration, grading, plagiarism detection, admin tooling.

\subsection{Acceptance criteria (verifiable)}
\begin{enumerate}
\item \texttt{npm run build} succeeds with all 33 indexable URLs prerendered (verified 2026-10-11). \textbf{Status:} IMPLEMENTED.
\item \texttt{/compiler} renders the runtime switcher plus one \texttt{iframe\#onecompiler} whose \texttt{src} changes with the selected language. \textbf{Status:} IMPLEMENTED.
\item Every indexable route exposes a unique title, description, canonical URL, and breadcrumb trail (verified by code inspection). \textbf{Status:} IMPLEMENTED.
\item With network access to \texttt{onecompiler.com}, the iframe loads the editor; without it, the page frame still renders. \textbf{Status:} INFERRED (third-party behavior, not mocked in repo).
\end{enumerate}

\subsection{Constraints, dependencies, risks}
Constraint: all execution capability is delegated to OneCompiler; CodeLab cannot fix editor bugs or guarantee language availability. Dependency: public internet + \texttt{onecompiler.com} availability. Risk: embed policy or URL-schema changes break the playground without a CodeLab code change. Mitigation (RECOMMENDED): pin and document a known-good embed URL and add a smoke check (see Section~\ref{sec:roadmap}).
