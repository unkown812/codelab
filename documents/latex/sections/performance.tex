\section{Performance and Scalability}
\label{sec:performance}

\textbf{Status:} INFERRED (no measurements, budgets, or load tests exist in the repository).

\subsection{Performance}
Each page ships static HTML plus the React runtime plus, on playground routes, one lazily-loaded third-party iframe. Expected cost centers: (1) Next.js JS bundle, (2) Inter/Plex Mono webfont loading via \texttt{next/font}, (3) the OneCompiler app inside the iframe, which dominates interactive readiness. Implemented mitigations: static prerendering of all 33 URLs, \texttt{loading="lazy"} on iframes, explicit \texttt{next/image} dimensions for logos, two minimal client islands, no analytics or ad scripts. Not implemented: bundle analysis, \texttt{next/image} beyond logos (no photo assets exist), or Web Vitals reporting.

\subsection{Scalability}
CodeLab-side scaling is trivially horizontal: the routes are static with no session state, so any static host or CDN can serve them. Effective scalability is bounded by OneCompiler's availability and rate limits, which are outside this repository. No caching, queueing, or database scaling considerations apply. \textbf{Status:} NOT APPLICABLE beyond CDN static hosting.
